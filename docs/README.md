# Netflix Clone
**Status:** In Progress  
**Description:** Clone of Netflix. 
- Frontend NextJs
- Backend - SpringBoot + ExpressJs ( Separate )
- Database - Springboot - MySql | ExpressJS - MongoDB

**Key Features:**
- User Login,User SignUp
- Movie List
- Tv Series List
- reviews
- user wishlist for save watching,watched and to be watched
- Admin Panel - Add / Edit / Delete Movies
- Review Management

**Technologies:**

- Session Management
- JWT Cookies
- Refresh Tokens
